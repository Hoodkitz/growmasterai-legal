# GrowMaster AI — Legal Pages

This repository hosts the static legal pages for **GrowMaster AI**, served via [GitHub Pages](https://hoodkitz.github.io/growmasterai-legal/).

## Pages

| File | Description |
|------|-------------|
| `index.html` | Legal hub / landing |
| `privacy.html` | Privacy Policy |
| `terms.html` | Terms of Service |
| `imprint.html` | Imprint / Legal Notice |

## Deployment

Pages are automatically deployed to GitHub Pages on every push to `main` via the workflow at `.github/workflows/pages.yml`.

## Local Preview

Open any `.html` file directly in a browser, or use a simple local server:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.
